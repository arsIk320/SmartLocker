# Алгоритм построения карты лица по одному фото

## Назначение

Алгоритм предназначен для построения карты лица по одному изображению. Под картой лица понимается не само фото, а числовой вектор признаков лица, который можно сохранить и затем использовать для сравнения.

## Входные данные

- одно фото пользователя;
- допустимые форматы: `jpg`, `jpeg`, `png`.

## Выходные данные

Результат работы алгоритма:

- `embedding` - числовой вектор признаков лица;
- `embedding_size` - длина вектора;
- `bbox` - координаты найденного лица;
- `landmarks` - ключевые точки лица;
- `quality_score` - оценка качества фото;
- `model_version` - версия модели извлечения признаков.

## Основной алгоритм

### Шаг 1. Загрузка изображения

1. Принять входное фото.
2. Проверить, что файл существует и не пустой.
3. Проверить, что формат изображения поддерживается.
4. Декодировать изображение в рабочий формат.

Если изображение не читается, вернуть ошибку `invalid_image`.

### Шаг 2. Нормализация входного изображения

1. Привести изображение к цветовому пространству `RGB`.
2. Удалить служебный поворот по `EXIF`, если он есть.
3. При необходимости уменьшить изображение до рабочего размера.
4. Сохранить пропорции изображения.

Цель этого шага - привести все входные фото к предсказуемому виду перед обработкой.

### Шаг 3. Обнаружение лица

1. Запустить модель детекции лиц.
2. Получить список найденных лиц.

Правила:

- если лицо не найдено, вернуть ошибку `face_not_found`;
- если найдено несколько лиц, вернуть ошибку `multiple_faces` или выбрать самое крупное лицо как основное;
- если найдено одно лицо, перейти к следующему шагу.

Результат шага:

- `bbox` - прямоугольник лица на исходном изображении.

### Шаг 4. Поиск ключевых точек лица

Для найденного лица определить ключевые точки:

- левый глаз;
- правый глаз;
- кончик носа;
- левый угол рта;
- правый угол рта.

Результат шага:

- `landmarks` - координаты ключевых точек лица.

### Шаг 5. Проверка качества лица

Для найденного лица вычислить итоговую оценку качества `quality_score`.

Проверяются:

- лицо достаточно крупное относительно размера кадра;
- изображение не размыто;
- лицо не слишком тёмное;
- лицо не пересвечено;
- поворот головы находится в допустимых пределах;
- лицо не обрезано краями изображения;
- ключевые точки определены стабильно.

Если `quality_score` ниже заданного порога, вернуть ошибку `low_quality`.

### Шаг 6. Геометрическое выравнивание

1. Повернуть лицо так, чтобы линия глаз была горизонтальной.
2. Привести лицо к эталонному масштабу.
3. Отцентрировать лицо по глазам и носу.

Цель этого шага - получить одинаковое положение лица независимо от наклона головы на исходном фото.

### Шаг 7. Вырезание нормализованного фрагмента

1. Вырезать область лица фиксированного размера.
2. Использовать единый размер входа для модели, например:
   - `112x112`, или
   - `160x160`.

Результат шага:

- нормализованный `face crop`.

### Шаг 8. Фотометрическая нормализация

1. Привести значения пикселей к диапазону, ожидаемому моделью.
2. Стабилизировать яркость и контраст.
3. Подготовить массив пикселей к передаче в модель признаков.

### Шаг 9. Извлечение признаков лица

1. Передать нормализованный фрагмент лица в модель распознавания лиц.
2. Получить вектор признаков `embedding`.

Пример:

- длина вектора `128`, `256` или `512` значений.

### Шаг 10. Нормализация вектора признаков

1. Выполнить `L2-нормализацию` вектора.
2. Получить итоговую карту лица.

После этого карта лица готова к сохранению и дальнейшему сравнению.

## Формат карты лица

Пример итогового объекта:

```json

  "embedding_size": 512,
  "bbox": {
    "x": 184,
    "y": 96,
    "w": 220,
    "h": 220
  },
  "landmarks": {

  "model_version": "face-model-v1"
```

## Псевдокод

```python
def build_face_map(photo):
    image = load_image(photo)
    if image is None:
        return error("invalid_image")

    image = normalize_input(image)

    faces = detect_faces(image)
    if len(faces) == 0:
        return error("face_not_found")
    if len(faces) > 1:
        return error("multiple_faces")

    face = faces[0]
    bbox = face.bbox

    landmarks = detect_landmarks(image, bbox)

    quality_score = estimate_quality(image, bbox, landmarks)
    if quality_score < QUALITY_THRESHOLD:
        return error("low_quality")

    aligned_face = align_face(image, landmarks)
    face_crop = crop_face(aligned_face, size=(112, 112))
    face_crop = normalize_pixels(face_crop)

    embedding = extract_embedding(face_crop)
    embedding = l2_normalize(embedding)

    return {
        "embedding": embedding,
        "embedding_size": len(embedding),
        "bbox": bbox,
        "landmarks": landmarks,
        "quality_score": quality_score,
        "model_version": "face-model-v1",
    }
```

## Короткая схема пайплайна

`photo -> detect face -> landmarks -> quality check -> align -> crop -> normalize -> embedding -> face map`

## Ограничение текущей версии

Этот алгоритм строит карту лица по одному фото, но не решает надёжно задачу определения, что перед камерой живой человек, а не фото на бумаге или изображение на экране устройства.
